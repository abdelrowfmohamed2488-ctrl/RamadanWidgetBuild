# عدّاد رمضان 2027 — تطبيق أندرويد مع ويدجت حقيقية

تطبيق عربي بتصميم أخضر داكن وذهبي، ويحتوي على ويدجت للشاشة الرئيسية تعرض الأيام والساعات والدقائق المتبقية. التاريخ التقديري المستخدم: 8 فبراير 2027 بتوقيت القاهرة، وقد يتغير حسب رؤية الهلال والإعلان الرسمي.

## بناء ملف APK من الموبايل فقط
1. نزّل ملف ZIP للمشروع وفك ضغطه على الموبايل.
2. افتح github.com من المتصفح وأنشئ مستودعًا جديدًا (Repository) باسم `RamadanCountdown2027` واجعله Public أو Private.
3. ارفع محتويات المجلد إلى المستودع مع الحفاظ على المجلدات، ومنها `.github/workflows/build-apk.yml`.
4. افتح تبويب Actions، واختر `Build Ramadan Countdown APK`، ثم اضغط `Run workflow`.
5. بعد نجاح البناء، افتح نتيجة التشغيل وانزل إلى Artifacts ثم نزّل `RamadanCountdown2027-APK.zip`، وافتحه وثبّت `app-debug.apk`. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.
6. لإضافة الويدجت: اضغط مطولًا على مساحة فارغة بالشاشة الرئيسية > Widgets/الأدوات > عدّاد رمضان 2027، ثم اسحب الويدجت للشاشة.

ملاحظة: أندرويد يتحكم في معدل تحديث الويدجت، وقد لا يحدّثها كل دقيقة؛ التحديث الدوري مضبوط على نحو 30 دقيقة، مع إعادة تحديثها عند طلب النظام. يلزم اتصال إنترنت عند رفع المشروع وبناء APK عبر GitHub Actions، لكن التطبيق نفسه لا يحتاج الإنترنت للعدّاد.
